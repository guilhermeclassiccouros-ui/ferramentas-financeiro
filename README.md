# Ferramentas Financeiro

Plataforma de ferramentas para o setor financeiro, organizada em módulos independentes.

## Status atual

- ✅ Folha de Pagamento (funcional)
- 🔜 PDF Suite Pro
- 🔜 BankMatch
- 🔜 Renomeador ML
- 🔜 Renomeador Pagamentos Diários
- 🔜 Renomeador Exportação

## Estrutura do projeto

```
ferramentas-financeiro/
├── index.html
├── README.md
└── modulos/
    └── folha-pagamento/
        └── index.html
```

## Como rodar localmente

Cada módulo é uma aplicação HTML independente. Basta abrir o arquivo index.html do módulo desejado em um navegador.

## Hospedagem

O projeto é publicado via Vercel, conectado diretamente a este repositório GitHub.
